# Autonomous Driving EV Car with Battery Monitoring

This project uses Arduino UNO for ultrasonic obstacle detection and vehicle control, while ESP32 monitors the EV battery voltage.

## Features
- Ultrasonic obstacle detection
- Autonomous vehicle control
- Battery voltage monitoring using ESP32
- Blynk IoT dashboard integration

## Hardware
- Arduino UNO
- ESP32
- Ultrasonic sensor
- Motor driver and DC motors
- Battery pack and voltage divider
- Servo motor
